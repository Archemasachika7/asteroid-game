# Asteroid Run

A dependency-free HTML Canvas arcade game with keyboard and touch controls.

## Play
Open index.html in a modern browser. No installation or API keys required.
Keep index.html, style.css, and game.js together.

## Controls
- Left/right arrows or A/D: rotate
- Up arrow or W: thrust
- Space: shoot
- P: pause/resume
- R: restart
- Touch buttons: rotate, thrust, shoot, and pause

## Features
Splitting asteroids, increasing waves, three lives, temporary respawn protection,
particles, screen wrapping, pause on focus loss, and local best-score storage.
